# Vamshi Peram — Portfolio

A responsive personal portfolio built with React, Vite, TypeScript, and CSS.

## Requirements

- Node.js 20 or newer
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Before publishing

1. Add your current resume as `public/resume.pdf`.
2. Verify all project descriptions and links.
3. Replace any project illustration with a real screenshot where available.
4. Test the production build and mobile layout.
5. Deploy the repository through Netlify or Vercel.

## Notes

- Project case studies are portfolio narratives, not claims that the live applications have been independently verified.
- The contact section uses a mailto link for the first release; it does not currently submit a backend form.
- The project detail pages are designed to work through React Router. Configure SPA fallback on the hosting provider if needed.
